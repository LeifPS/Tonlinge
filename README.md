# Tonlinge

Ein handgezeichnetes 2D-Browserspiel: Finde Instrumente, fange Tonlinge mit Tönen und Frequenzen, erkunde Klanghain und Glimmerhöhlen.

- Spielen: `index.html` im Browser öffnen (eine einzelne Datei, kein Server nötig).
- Quellcode: `src/`. Mit `./build.sh` wird daraus wieder `index.html` gebaut.
- Spielstand wird im Browser (localStorage) gespeichert.
